# E3 Reference Format v0.1

Used by the [evaluation workflow](../architecture/e3-evaluation-workflow.md).
Reference origin and uncertainty matter independently of numeric agreement.
Do not confirm a file solely because it was generated by an assistant or model.

## Bundle Manifest

`manifest.json` holds draft clip entries: source absolute path/SHA-256, case,
participant/source-group ID, reviewed provenance, development-use status, body
side/facing and relative review/reference paths. Initial values are unknown.
`known_source_match` is diagnostic; eligibility rechecks actual hashes and local
development-smoke history. Manually clearing that field cannot approve a source.

Cases are `compliant`, `wrong_view`, `required_joint_occlusion`, and
`timing_discontinuity_or_unknown_cadence`. For a negative case list all metric
IDs in exactly one of `expected_affected_items`/`expected_unaffected_items`:

`knee_flexion`, `hip_flexion`, `torso_lean`, `relative_descent`, `hip_to_knee_gap`,
`raw_knee_travel`, `foot_normalized_knee_travel`, `heel_rise_magnitude`,
`total_duration`.

For a global wrong view, all may be affected and none unaffected. Occlusion or
timing cases must preserve at least one unrelated item. Expectations are reviewed
before running, not copied from measured gate output after a failure. Wrong-view
cases need a false side-view review; occlusion needs a false joint-visibility
condition; timing cases cannot have both continuity/cadence approved.

## Review File

`reviews/clip-NNN.json` uses the [recording review](../architecture/recording-review.md)
schema: exact video filename, size, mtime and side-specific records. A named
reviewer and true required flags are necessary for compliant items; false means
known failure, null means unknown. Template fields do not imply approval.

## Reference File

The following is an incomplete format illustration, not reference data:

```json
{
  "schema_version": 1,
  "source_sha256": "copy the registered source hash",
  "confirmed": false,
  "reviewer": null,
  "origin": null,
  "notes": "No actual values or events confirmed",
  "repetitions": [],
  "frame_measurements": []
}
```

Confirmation requires `confirmed: true`, a named reviewer, and origin exactly
`independent_review`. Unsupported schema, stale source hashes, missing values,
quota failures or unresolved uncertainty prevent primary freeze. An author can
assert review, but software cannot establish honesty or anatomical truth.

Each complete reference repetition contains:

- `start_source`: zero-based departure from standing; include an earlier standing frame.
- `deepest_interval`: inclusive `[first, last]` reviewed deepest-posture interval.
- `end_source`: return to standing; require start < deepest interval < end.
- `uncertainty_frames`: nonnegative reviewed uncertainty, at most two frames.
- `metrics`: every scalar metric ID except total duration, each with independently
  established numeric `value` and nonnegative `uncertainty` in protocol units.

Repetitions are chronological/nonoverlapping; initial/final partials and setup
are excluded. Genuine bottom plateaus have documented intervals; do not widen
an interval to cover prediction errors. Count references without boundaries are
not sufficient. Total reference duration is derived from reviewed start/end
events only when constant FPS is reviewed.

Framewise references use records `{ "metric": ..., "source_frame": ...,
"value": ..., "uncertainty": ... }` for knee flexion, hip flexion and torso lean.
Exactly ten prescribed frames are required for each: standing before the first
complete start, then descent midpoint, deepest point and ascent midpoint for
the first three complete cycles. Source positions are determined from reviewed
events before inspecting predictions. The tool uses the preceding frame,
integer temporal midpoints, and middle of the deepest interval. Different
semantics require a new protocol, not post-result selection of easier frames.

## Meaning of Numeric References

Angles use the catalog's aspect-corrected 2D convention (original pixel geometry),
zero flexion at extension, torso magnitude from vertical. They are not 3D angles.
Image-axis measurements use normalized source height/width as declared in
`e3-limits-v0.1.json`; ratios require independently reviewed baselines/denominators.

Per-repetition references must represent the same observable as the metric:
bottom angles/gap at the reviewed deepest posture; torso maximum over its
reviewed cycle; signed maximum knee travel; foot-normalized travel using the
reviewed foot reference; heel-rise magnitude relative to a reviewed planted
start baseline; relative descent with a reviewed standing/bottom reference.
Selected frame values alone do not validate repetition maxima. Record extremum
locations/baseline conventions and review uncertainty in notes/evidence.

Angle-reference uncertainty must be at most two degrees; derived-reference
uncertainty at most half the metric MAE target. Propagate coordinate/baseline
uncertainty instead of assuming exact numbers. Open uncertainties remain pending.
Physical heel-lift duration and pause-event labels are not accepted as validated
by the current arithmetic checks. See the [predeclared protocol](E3_PROTOCOL_v0.1.md).
