# Session 2026-07-28

## Decisions Made

- Preserve existing pose and metric APIs while correcting misspelled public
  names through backward-compatible aliases.
- Keep `PoseSequence` as a list alias and add `PoseExtractionResult` for source
  frame mapping instead of replacing the existing pose data model.
- Define `SquatRep.bottom_index` as the final frame classified as `BOTTOM`, not
  necessarily the deepest physical frame.
- Treat current squat depth as a relative hip-descent MVP proxy.
- Keep biomechanical measurement separate from future adaptive feedback rules.
- Adopt the side-view MVP metric portfolio recorded in ADR-013 and ADR-014:
  direct measurements for depth, joint angles, torso lean, normalized knee
  travel, heel lift, timing, consistency, and confidence; conservative
  multi-measurement inferences for trunk collapse and ankle mobility.
